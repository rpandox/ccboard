A row that says "dropped" is a block of "What v0.x adds" prose whose facts were already in [ROADMAP.md](../ROADMAP.md) and CHANGELOG.md; where only some bullets of a block were dropped, the row points at the page and heading that kept the rest. Headings in the first column are the old names, labels included. This table is temporary. Delete it after two releases.
